## 0.18.0 — GitHub-ready prototype

This release consolidates the earlier 0.1–0.17 prototype iterations into one documented baseline. Database migration files and the existing hosted Git history are preserved.

- Catalog: one subcategory level, category pricing, editable items/categories, fandom colors, search, a fandom-grouped button grid and sortable table.
- Checkout: visual deal boxes, category eligibility, buy/get-free and $/% deals, custom discounts, physical-item tracking and Square subtotal.
- Conventions: editable names, application statuses, year filters, daily/all-days dashboards, transaction deletion and Excel exports.
- Earnings & Expenses: accepted/historical conventions, manual totals or extra income, commissions, creator programs, expenses and yearly totals.
- Storage: artist-isolated hosted workspaces, indexed transactions/finance, offline browser checkout with safe retries, standalone SQLite, portable JSON backups and guarded restore/migrations.
- Source cleanup: remove unused UI/scaffolding and dependencies, share category rendering and test setup, enforce unused-code checks and add one verification command.
- Offline cache versions now follow asset content; ordinary UI edits no longer require a release-number bump.
- Document source installation, Git/ZIP updates, moving data to another computer and GitHub contribution/release workflows.
